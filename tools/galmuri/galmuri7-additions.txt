# Cyrillic and Greek for Galmuri7, which has neither, drawn in its style: capitals 7 rows
# tall, lowercase 5, one row below the baseline, accents in the rows above.
# tools/galmuri_afterglow.py adds these to Galmuri7 and writes Galmuri Afterglow.
#
#   CHAR ROW          a glyph drawn below, its first line at ROW (6 = a capital's top,
#   lines...          4 = lowercase's top, 0 = the baseline, -1 = below it); `#` is ink,
#                     and an empty row is a `.`
#   CHAR = OTHER      the same as OTHER, a letter Galmuri7 already has
#   CHAR = OTHER + M  OTHER with mark M - acute, grave, diaeresis, breve - taken from
#                     Galmuri7's own é è ë ă; on a capital, Galmuri7's way: the capital a
#                     row shorter, the mark above it. `tonos` sets a capital's mark at its
#                     left, as Greek does.
# A glyph is as wide as its widest line, and advances one more.
